**Goal:** the `@`-mention picker becomes the pixel-faithful port of upstream
v1.18.18 `@`-completion (spec §1): the bordered-dropdown chrome (the slash epic's
`dropdown.go` primitive) anchored above the input (home — above the box top edge;
session — the current placement with the new chrome), the files + directories
candidate source (TUI-local walk, zero-MCP — the upstream agent/MCP/reference
candidates are NOT ported), the positive-score threshold gate + prefix ×2 +
frecency ×(1+f) ranking (cap 10, no scroll), keyboard (up/down wrap, `enter`
inserts, `tab` completes, `esc` strips) and mouse (hover moves selection, click
inserts) parity, the `@`-wins-over-`/` precedence, the `No matching items` empty
text, the home hint's `tab complete` extension, and the `DEVIATIONS.md` entries
+ re-baselines. No new dependencies; zero telemetry. The command palette is out
of scope (sibling epic `yolo-hb0`, blocked-by this epic).

**Architecture:** S1 renders the `@` menu through the slash epic's shared
`dropdown.go` primitive (the bordered box, the `primary`-bg /
`selectedForeground`-fg selection row, the two-column row layout with the
`truncateMiddle` path column, the home anchor above the box top edge at
`boxL`/`boxW`, the session placement unchanged) and lands the
`@`-wins-over-`/` precedence gate (`slashActive` suppressed while a valid `@`
trigger is present — one suppression point covering the render and the key
ladder). S2 reworks the candidate source: the walk also collects directories
(preorder, files-only cap unchanged), the positive-score fuzzy gate, the
`mentionOption{path, isDir}` value carrier (directory rows gain the trailing `/`
marker), and the query-change `sel`→0 reset. S3 lands the insert semantics:
`@<path> ` on files (space only when the char after the replaced range is not a
space — the value-derived model's query reaches the end, so the space is always
appended), directory + `tab` = the `@<path>/` expand (no trailing space, the menu
stays open, `sel`→0), directory + `enter`/click = the file semantics; the
frecency touch stays insert-only. S4 lands the mouse: hover = move `sel`, click
= the enter action (no expand on click) — riding the slash epic's app-level
`tea.MouseMsg` case + `main.go:768` `tea.WithMouseCellMotion` (if the slash epic
has not landed the option, this task lands it). S5 lands the key interplay:
`tab` in the `@` handler (complete: file = insert + close, directory = expand)
owned before `agent_cycle`, `shift+tab` unchanged, and the home hint's `tab
agents` segment → `tab complete` while either menu is open. S6 lands the
`No matching items` empty text, the §5 re-baselines, the third home mock, and
the `DEVIATIONS.md` entries 312-317 last.
