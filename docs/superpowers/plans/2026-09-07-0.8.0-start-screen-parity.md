# 0.8.0 Start-Screen Parity Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: use superpowers:executing-plans (or
> superpowers:subagent-driven-development) to implement this plan task-by-task.
> Steps use checkbox (`- [ ]`) syntax for tracking. Every task ends gate-green
> with ONE commit carrying the plan-pinned message.

**Goal:** Bring the yolo TUI **home route** (start screen) to the 0.8.0
parity target — the accepted mock (`docs/superpowers/mockups/home-mock-200x50.txt`,
generated by `internal/tui/home_mock_test.go`): centered logo, 75-wide prompt
box with placeholder + `agent · model provider` meta line, `tab agents
ctrl+p commands` hint line, centered tip, and the upstream home footer
(`path[:branch] … <plain semver version>`, zero-MCP). The session list leaves
the start screen. Every delta is either copied (strict-copy bar) or logged as
a deviation (epic `yolo-dhf`, decisions on `yolo-dhf.2`).

**Architecture:** The home route becomes an OWNED full-terminal frame
(`App.homeView`, Task 4) instead of an unbounded block plus appended
prompt/footer lines (the Q9 off-screen bug): a fixed 20-row centered stack
(4-row pad, 4-row logo, 1-row pad, 1-row box pad, 5-row prompt box, 1-row
hint, 3-row tip pad, 1-row tip) plus overlay rows, spacers split
ceil-first, and a 3-row footer block (pad / content / pad). The prompt box
reuses the shared `textinput` (editing state shared with the session route)
but renders its own interior rows for width-exact bg fill (Task 5). New
TUI-local state: `pendingAgent` (agent cycling, Task 7), `version`
(plain-semver, Task 1), `branch` (git detection, Tasks 2–3), and the prompt
`mode` ("normal"/"shell") + placeholder index (Task 10). The shell run path
is a new `POST /session/{id}/shell` endpoint (Task 9) backed by
`Engine.Shell` (Task 8): it persists the synthetic user part + assistant
message carrying an EXISTING `bash` tool part and executes through the
existing per-session persistent shell (`Engine.shellFor` + the `bash` tool's
`Run` — no new part kind, no new tool). No new runtime dependencies (git via
stdlib `os/exec`), no core protocol changes beyond the one new endpoint.

**Tech Stack:** Go 1.26 (module requires ≥ 1.25); allowlist runtime deps
UNCHANGED (`charm.land/bubbletea/v2` v2.0.9, `lipgloss/v2` v2.0.6,
`bubbles/v2` v2.2.1, `modernc.org/sqlite`, …). TUI textinput API in use:
`Value()`, `Position()` (cursor offset), `SetWidth`, `Placeholder`,
`Styles()`. Dev-only: teatest/v2 (SGR goldens), git binary in the test
environment (local only, no network).

## Task 2 — VCS branch detection, core (D — granular)

Pinned commit: `feat: git branch detection via stdlib os/exec`

Decision 4 (yolo-dhf.2): stdlib `os/exec` git shell-out mirroring upstream
v1.18.18 (`packages/opencode/src/git/index.ts` — the pinned `cfg` arg
constant + `branch()`), NO external git dependency. New file
`internal/tui/vcs.go` (TUI-side: the footer renders from the TUI's scope dir

- [ ] **Step 1 — `findGitRoot`.** Walk up from `dir` (to the filesystem
  root) and return the nearest ancestor containing a `.git` entry (file OR
  directory — worktrees/submodules), `("", false)` when none (incl.
  `dir == ""`). Pure stdlib (`os.Stat`/`filepath`). Unit tests:
  - `.git` DIRECTORY at dir itself → dir;
  - `.git` FILE (worktree) at an ancestor → that ancestor;
  - subdir under a repo → the repo root;
  - plain temp dir (no `.git` anywhere under the temp root — create the
    fixture INSIDE `t.TempDir()` so the walk can never escape into the
    test environment's real repo) → `("", false)`;
  - `dir == ""` → `("", false)`.
- [ ] **Step 2 — `gitBranch` core.**
  ```go
  // gitBranch resolves the attached branch of the repo containing dir
  // ("" + ok=false when none): it requires findGitRoot(dir) to succeed
  // (no .git -> no spawn), then runs
  //   git <gitBranchArgs>
  // with cwd = dir (git walks up itself from there), the caller-supplied
  // env, and the timeout ctx. Exit table (decision 4): 0 -> the trimmed
  // stdout ("" -> none); 1 -> detached HEAD -> none; 128 -> non-repo ->
  // none; exec.ErrNotFound -> no git binary -> none; ctx deadline
  // exceeded -> none; any other exit -> none. ok=false for every none
  // case (the caller renders the path-only footer).
  func gitBranch(ctx context.Context, dir string, timeout time.Duration, env []string) (string, bool)
  ```
  with the pinned upstream arg prefix (git/index.ts `cfg` const, verbatim):
  ```go
  var gitBranchArgs = []string{
      "--no-optional-locks",
      "-c", "core.autocrlf=false",
      "-c", "core.fsmonitor=false",
      "-c", "core.longpaths=true",
      "-c", "core.symlinks=true",
      "-c", "core.quotepath=false",
      "symbolic-ref", "--quiet", "--short", "HEAD",
  }
  ```
  (`exec.CommandContext(ctx, "git", gitBranchArgs...)`; `cmd.Dir = dir`;
  `cmd.Env = env`; stdout captured; stderr discarded.) Unit tests (each a
  fresh `t.TempDir()`, git via `exec.Command("git", ...)` in the test setup
  — local only):
  - attached branch: `git init -q` + `git checkout -q -b yolo-test-branch`
    (no commit needed) → `("yolo-test-branch", true)`;
  - subdir of the repo (walk-up + git's own walk) → same;
  - detached: create one commit (`-c user.email=t@t -c user.name=t
    commit -q --allow-empty -m x`) then `git checkout -q --detach` →
    `("", false)` (exit 1);
  - no `.git` anywhere → `("", false)` WITHOUT spawning git: put a fake
    `git` script (a temp-dir executable that `touch`es a marker file, then
    exits 0 with `HEAD` on stdout) on a temp PATH and pass it via `env`;
    assert the result is `("", false)` AND the marker file was never
    created (the findGitRoot short-circuit skips the exec);
  - no git binary: `env = []string{"PATH=" + emptyTempDir}` → `("", false)`
    (exec.ErrNotFound);
  - timeout: a temp dir containing an executable `git` script
    (`#!/bin/sh\nsleep 5`, chmod 0755) prepended to PATH, `timeout =
    200*time.Millisecond` → `("", false)` (deadline exceeded).
- [ ] **Step 3 — env hardening (decision 4, deliberate deviations).**
  ```go

  // GIT_DIR/GIT_WORK_TREE/GIT_INDEX_FILE/GIT_CEILING_DIRECTORIES/
  // GIT_COMMON_DIR (a repo-local or hook-set GIT_* must not redirect the
  // probe away from the scope dir) plus GIT_TERMINAL_PROMPT=0 (no
  // credential prompt on a read-only probe).
  func sanitizedGitEnv() []string
  ```
  Unit tests:
  - the 5 vars stripped + `GIT_TERMINAL_PROMPT=0` present, other vars kept;
  - hardening proof: an unrelated repo B on branch `elsewhere` + the probe
    dir A on branch `yolo-test-branch`; env built from
    `[]string{"GIT_DIR=" + B + "/.git"}` + sanitized passthrough → result is
    STILL `yolo-test-branch` (the strip wins over the parent env's
    GIT_DIR).
