**Goal:** the `ctrl+p` command palette becomes the pixel-faithful port of
upstream v1.18.18 `CommandPaletteDialog` (spec §1): the fullscreen dim backdrop
(decision D — the flat pre-blended `rgba(0,0,0,150/255)` field, superseding
deviation 166), the `Suggested` seed bucket (decision A) + the five
client-side categories (decision B) with the accent BOLD headers, the title×2 +
category×1 positive-score filter (no threshold, no cap — the scroll window
`floor(h/2) − 6`), the arrow/enter/page/home/end key set with run-on-enter
(`esc`/`ctrl+c` close — the prompt untouched), mouse (hover moves selection,
click runs), the inner-line parity (the title-row `esc` hint + the `ctrl+p
commands` footer hint), the `No results found` empty text (already parity —
verified, unchanged), and the `DEVIATIONS.md` entries 318-321 + re-baselines.
No new dependencies; zero telemetry; no wire change. The palette is
**command-only** (no agent-as-item, no file candidates — those are the
`@`-picker's domain or have no yolo referent) and is NOT a `dropdown.go`
consumer (locked decision 1 — it keeps its own borderless `backgroundPanel`
modal, view.go:212).

  ends gate-green with ONE commit carrying the plan-pinned message.

  `plan/menu-parity-0.10.0` (checked out; based on latest main @ `78d518a`),
  one task at a time. Checkpoint commits between tasks: `docs: checkpoint —
  Task N (<name>) done, next is Task N+1 (<name>)`.

  (`bd update yolo-nsw --claim --json`, then the next in the chain); close it

  implementation → gate green → commit with the pinned message.

  unchanged; every import this plan adds is stdlib or an existing allowlisted
  module (lipgloss v2, bubbletea v2, the stdlib math for the blend).
