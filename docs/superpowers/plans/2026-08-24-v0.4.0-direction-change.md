# v0.4.0 Direction Change Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Restate the living docs (root + internal AGENTS.md chain, README,
PROGRESS.md) to the approved v0.4.0 direction change — new purpose,
reference-not-contract policy, re-baselineable pins — with zero code changes.

**Architecture:** Four small doc tasks on branch `v0.4.0_spec`, each
restating one doc to the canonical wording of spec §2 (which carries the
exact restated principle text). The spec is the single source of the new
wording; every task ends with the CI gate green and a commit with the pinned
message. Task 4's DOX closeout also removes the two stale "intentional
deviation" index lines in the internal DOX chain (`internal/AGENTS.md`
Child DOX Index + `internal/protocol/AGENTS.md` Local Contracts) — mandated
by the DOX framework's "remove stale or contradictory text immediately".

**Tech Stack:** Markdown only; the Go CI gate (`go vet ./... && go test
./...`) runs for discipline even though no code changes.

**Spec:** `docs/superpowers/specs/2026-08-24-v0.4.0-design.md`

## Global Constraints

- Spec §2.2/§2.3 blockquotes are the verbatim target wording for root
  AGENTS.md core principles 2 and 3 (numbering `2.` / `3.` unchanged).
- Zero telemetry (root principle 1) is unchanged.
- The mirrored REST/SSE baseline and the `x-yolo-directory` standing baseline
  deviation are unchanged.
- Historical dated specs / plans / reviews / archives under
  `docs/superpowers/` are immutable — never reword them.
- No code, dependency, config, or behavior changes.
- Gate at module root after every task: `go vet ./... && go test ./...`
  green and `gofmt -l .` prints nothing.
- Commits land on `v0.4.0_spec` only (never `main`), conventional,
  imperative, ≤ 72-char subject, exact pinned message per task.
- DOX pass after every doc edit: re-check changed paths against the DOX
  chain, update nearest owning doc + affected Child DOX Indexes, remove
  stale text.
- Beads: Tasks 1–4 execute under bead `yolo-5u1.2` (epic `yolo-5u1`); one
  subagent at a time (root principle 7).

**yolo** is a faithful Go port of [opencode](https://github.com/anomalyco/opencode) **v1.18.18** — TUI + core server only (web/desktop/slack/console dropped). Purpose: test the capabilities of **Qwen3.8-27B** on a single RTX 5090 behind `https://ai.kido.ws/v1`.

New (exact):

```
**yolo** is a Go TUI + core-server harness in the lineage of [opencode](https://github.com/anomalyco/opencode) **v1.18.18** (TUI + core server only; web/desktop/slack/console dropped). It began as a faithful port whose purpose was to test the capabilities of **Qwen3.8-27B** on a single RTX 5090 behind `https://ai.kido.ws/v1` — that goal is complete (local Qwen 3.8 tested, stable, optimized; the v0.3.0 tree is the stable baseline). From v0.4.0 the project's purpose is to **test various LLM harnesses and frameworks** (yolo drives and evaluates other harnesses). opencode remains a **reference** for how things should be done, not a binding contract (core principle 2; spec `docs/superpowers/specs/2026-08-24-v0.4.0-design.md`).
```

- [ ] **Step 2: Replace core principle 2**

Old (exact):

```
2. **Faithful port, one deliberate wire deviation.** Legacy REST paths/JSON shapes and the legacy SSE event set are mirrored so the port is verifiable against opencode's OpenAPI contract. The single deviation: scoping header is **`x-yolo-directory`** (upstream: `x-opencode-directory`).
```

New (exact; spec §2.2 blockquote, bolded header style matched):

```
2. **Reference, not contract.** opencode v1.18.18 is a *reference* for how things should be done, not a binding contract. The legacy REST paths/JSON shapes and the legacy SSE event set remain mirrored so the baseline stays verifiable against opencode's OpenAPI contract, but yolo may deviate from upstream (wire shapes, behavior, pinned text) on explicit user instruction — every such deviation is logged in `docs/superpowers/DEVIATIONS.md` with severity. Standing baseline deviation: the scoping header is **`x-yolo-directory`** (upstream: `x-opencode-directory`).
```

- [ ] **Step 3: Replace core principle 3**

Old (exact):

```
3. **Verbatim pins are tests, not decoration.** 14 session prompt files and all tool `desc/*.txt` files are ported **byte-verbatim** from upstream and guarded by sha256 pins in tests. Do not "improve", rewrap, or reword pinned text.
```

New (exact; spec §2.3 blockquote):

```
3. **Pins are change gates, not upstream locks.** The 14 session prompt files and all tool `desc/*.txt` files are guarded by sha256 pins in tests. The pins record current intended content, not an upstream lock: pinned text may change in normal work, and an intentional change re-baselines the sha256 pin in the same commit. Never leave a pin dangling.
```
