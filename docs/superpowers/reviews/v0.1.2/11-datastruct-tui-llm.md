- [datastruct-1] P2 store/store.go:220 — `appendDelta` accumulates streamed text with `pr.Text += delta` (and `pr.State.Input["input"] = in + delta` at :229; reasoning default at :231): every SSE delta allocates a fresh string of the full accumulated length and copies it; a 10k-token stream is ~O(n²) memcopy per part. This is the hottest datastruct path (runs per token on every streamed response). — fix: keep a `strings.Builder` shadow per part (e.g. a `map[string]*strings.Builder` in Store keyed by partID, or a per-message field); on delta do `b.Write(delta); pr.Text = b.String()` (Builder.String() aliases without copy; the old header stays valid after regrowth). Preserves per-token display exactly. — contract-risk: none · status: FIXED 8a0c4b2
- [datastruct-2] P2 internal/tui/session.go:68 — `sync` unconditionally rebuilds the entire transcript via `renderMessages` on every frame; bubbletea v2 calls `View()` after every `Update` (verified tea.go:880), which includes the 10 Hz `spinMsg` ticks and busy status events where the transcript is unchanged. The `content != sm.content` gate only skips `SetContent` — the O(transcript) rebuild (per-part `strings.Split`, per-line lipgloss `Render`) happens anyway and is discarded. During a long-running tool (busy, no deltas) this wastes a full rebuild every 100 ms; `blocks` also grows unpreallocated (:85). — fix: dirty-flag the render (invalidate on store message mutation, expand toggle, resize) and skip `renderMessages` when clean; preallocate `blocks := make([]string, 0, len(st.Messages))`. — contract-risk: none · status: FIXED a74342a
- [datastruct-3] P2 internal/tui/app.go:768 — the three overlay views (`permissionView`, `toastsView`, `dlgView`) are each built twice per frame: once in `overlayLines` for line counting and again in `view` (:792, :796, :799) for output; `menuItems` is likewise re-filtered by both `menuLines` (:818) and `menuView` (:789). While the model dialog is open, the duplicated `dlgView` path re-runs `modelsOf` (map→`sort.Strings`→slice, model.go:97-106) and re-styles every row twice per frame, at streaming event rates. — fix: render overlays once per frame (e.g. compute the three overlay strings at the top of `view`/`viewSession` and reuse for the line count). — contract-risk: none · status: FIXED ec8c0cb

If an OpenAI-compatible server does not terminate the body after `[DONE]`, the reader goroutine and the whole engine round hang until the round ctx is cancelled. — fix: mirror the anthropic guard — `if finished { break }` after processing each line. — contract-risk: none · status: FIXED c8dabc3
