# golang-security — server+auth+config
Date: 2026-08-21 · chunk: server+auth+config · source files: 13
## Findings
- [security-1] P2 internal/server/server.go:163 — `Start` builds `&http.Server{Handler: s.handler}` with no `ReadHeaderTimeout`/`ReadTimeout`/`IdleTimeout`; the plan pins `yolo serve` on default port 4096 with `--addr`/`--port` flags, so a user can expose the core API beyond loopback, and any exposed bind is open to Slowloris-style read/header exhaustion (skill network.md rule 2; STRIDE Denial of Service) — fix: set `ReadHeaderTimeout` (~10s) and `ReadTimeout` (~30s) on the `http.Server`; do NOT set a small `IdleTimeout` or any `WriteTimeout` (the `GET /event` SSE stream is a long-lived writer that dies on a quiet bus); `MaxHeaderBytes` is already at Go's 1MB default — contract-risk: behavior (timeouts change observable connection behavior for slow/abusive clients; auto-deferred)
- [security-2] P2 internal/auth/auth.go:73 — `SaveTo` never re-chmods an existing `auth.json`: `os.WriteFile` applies 0o600 only when creating the file, so a pre-existing world-/group-readable auth.json (manually created, looser umask, third-party tooling) stays readable by other local users while it holds API keys (CWE-732; skill filesystem.md "0600 for secrets"); upstream opencode explicitly chmods after every write (`packages/opencode/src/auth/index.ts` set → `fsys.writeJson(file, data, 0o600)` → `packages/core/src/fs-util.ts:110-113` `if (mode) yield* fs.chmod(path, mode)`), so this is a port deviation that weakens security, not faithful behavior — fix: after the `os.WriteFile` at auth.go:73, `if err := os.Chmod(path, 0o600); err != nil { return err }` (idempotent) — contract-risk: none
- [security-3] P3 internal/provider/zen.go:170-174 — `writeAtomic` uses a predictable temp path (`cachePath + ".tmp"`) and `os.WriteFile` follows symlinks, so a local principal that can write inside the cache dir can pre-plant a symlink at `models.json.tmp` and redirect the catalog cache write to a file of its choice (skill filesystem.md "Insecure Temporary File Creation", CWE-379); mitigated by the owner-only cache dir (`MkdirAll 0o755`, zen.go:167 → only the owner can pre-plant) and the non-secret 8MB-bounded catalog content, leaving low residual risk — fix: `f, err := os.CreateTemp(filepath.Dir(p.cachePath), "models.json.*")` + write + close + `os.Rename` — contract-risk: none
