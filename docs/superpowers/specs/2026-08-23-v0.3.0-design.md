### 2.4 Upstream checks (v1.18.18)

**a. delete-while-busy [troubleshoot-5].** Upstream `Session.remove`
(`packages/opencode/src/session/session.ts:606-629`) cancels background
(subagent/task) jobs, recursively removes child sessions, deletes the
session's durable event rows in a transaction, and unregisters the aggregate —
but does NOT interrupt the in-flight main turn (it runs in the instance-scoped
`Runner`; `SessionRunState.cancel` is the separate abort path). Yolo has no
subagent jobs, no durable event rows, and a per-session engine: upstream parity
is structurally unachievable. Yolo today does none of it — `handleSessionDelete`
(`handlers_session.go:197-218`) only calls `Engine.Close` (`engine.go:249-259`),
events keep publishing and a post-Close bash re-spawns a leaked shell
(`engine.go:356-365`).

**b. part ordering [database-6].** Upstream orders parts by ID: `ORDER BY
PartTable.id` (`packages/opencode/src/session/message-v2.ts:499`); messages
`ORDER BY time_created DESC, id DESC` with cursor predicate
`lt(time) OR (eq(time) AND lt(id))` (`:439,:96`) — an explicit id tiebreaker.
Upstream IDs are timestamp-embedded crockford base32, so ID order = time order
+ deterministic tiebreak. **Yolo's IDs are crypto-random**
(`protocol/id.go:16-26`) — a verbatim `ORDER BY id` port would NOT reproduce
upstream semantics.

## 3. Plan 1 — design decisions

### 3.1 Engine lifecycle cluster (`internal/session`)

- **A. Panic recovery** (row 1): `runTurn`'s turn goroutine gets
  `recover()`; a recovered panic is logged (engine log, with session id), the
  turn is finalized as failed (session.status idle + turn error surfaced on the
  message), `onDone(err)` reports failure — no process crash, no false success.
  Test: a tool/driver panics → turn ends failed, process alive (fake driver
  with a panic hook).
- **B. Lone idle** (row 3): the Send early-fail path (CreateMessage/UpsertPart
  error) must publish busy before idle, or skip both and report the error via
  the existing failure channel only — pick "skip both" (no transition a client
  observed a start to is published); error still reaches the TUI. Wire-tagged:
  SSE frame sequence changes on the error path → deviation (wire, low).
- **C. Title goroutine lifecycle** (row 2; [design-3] folds in): the title
  goroutine moves off the 30 s `context.Background()` onto a tracked,
  cancellable ctx: spawned per session, cancelled by Abort, and Shutdown waits
  for in-flight title work (bounded, alongside the existing 5 s busy drain) so
  no `UpdateSession` / `session.updated` publish lands after the store closes.
- **D. Delete/Close while busy** (rows 2.2 + 2.4a): `DELETE /session/{id}` →
  `Engine.Close` becomes: (1) Abort the in-flight turn (turn ctx cancel),
  (2) mark the session deleted so event publishing is suppressed for it,
  (3) close the `tool.Shell` only after the turn has settled (deferred close;
  bounded wait, then hard close). **Deviation (behavior):** upstream lets the
  main turn run to completion in an instance-scoped runner; yolo aborts.
  Justification recorded in the deviation entry.
- **E. Abort TOCTOU** (row 4): cancel read + invocation of the stored cancel
  happen under the same lock acquisition (or the cancel is looked up and
  invoked atomically per-turn so a turn started in the window gets its own
  cancel, not the previous one's).
- **F. Part re-finalization / ID reuse** (row 14): mint a fresh part id per
  text block (upstream behavior) — a tool round that continues the same text
  stream after a tool call finalizes the pre-tool part and starts a new one.
  Wire-tagged: part-frame sequence and transcript structure change → deviation
  (wire, medium). Pins: engine_test.go + contract_test.go replay updated in
  the same commit.
- **G. gitCache** (row 19): the unbounded, non-expiring package-global
  git-dir cache becomes bounded (capped entry count) + expiring (TTL-based
  re-check) so a dir that becomes a git repo mid-process stops being
  permanently "no". Upstream check: `Is directory a git repo` renders from
  `ctx.project.vcs` (upstream `system.ts:79`), a persisted project property
  detected at project scan time — static per instance, never re-checked.
  Yolo's per-process cache is the faithful equivalent, so making it expire is
  a **deviation from upstream (behavior, low)** under the implement-everything
  policy; the env-block text is pinned by the prompt tests and the TTL is a
  new constant (plan fixes the value; default ~60 s).

### 3.2 Storage (`internal/storage`)

- **H. Marshal errors** (row 6): `ProtocolToPart` returns an error on
  `json.Marshal` failure (tool State, Text map) instead of persisting `""`;
  callers propagate. Test: NaN/Inf state → write fails, no 500-on-read row.
- **I. Deterministic ordering** (row 7, §2.4b): tie-break on SQLite `rowid`
  (insertion order, immutable per row, zero schema change): parts
  `ORDER BY time_created ASC, rowid ASC`; messages `ORDER BY time_created DESC,
  rowid DESC` with the cursor predicate extended to the same tie-break;
  permissions likewise. No wire change (order is already what clients see
  today in the deterministic case). No deviation.
- **J. RowsAffected errors** (row 10): a driver-level `RowsAffected()` error is
  returned, not mapped to `ErrNotFound`.
- **K. Context propagation** (row 16): in-place signature change — ctx as
  first parameter on every DAO method (no `*Context` variants); threaded from
  `r.Context()` in server handlers and the turn ctx in the engine. One large
  mechanical task; gate green per file-group commit.

### 3.3 Tools (`internal/tool`)

- **L. grep stat error** (row 11): os.Stat failure on the searched root
  returns a tool error (upstream parity), not "No files found".
- **M. EOF-without-marker** (row 8): the markerless-EOF branch returns a
  failure result (non-nil err / exit ≠ 0 surfaced in meta), not a successful
  Output with exit −1.
- **N. Myers line diff** (row 15): replace DP-LCS with a line-based optimal
  diff via **`github.com/aymanbagabas/go-udiff v0.4.1`** — actively maintained
  (pushed 2026-07-16), BSD-3-Clause, zero deps, pure Go (no cgo). A copy of
  `golang.org/x/tools`' internal diff package with exported symbols. Use
  `udiff.Lines(before, after) []Edit` ("all edits are at line boundaries",
  line-based optimal diff via its `lcs` subpackage); added/removed line counts
  derive from the edits (line count in each `New` vs its `[Start:End)` region)
  and match upstream's `diffLines` counts (both optimal line edits; counts are
  cleanup-invariant). Library selection (user ruled out `pmezard/go-difflib`
  as unmaintained on 2026-08-23): rejected `teleivo/diff` (GPL-3.0),
  `google/go-cmp` (comparator, no line-diff API), `hexops/gotextdiff` (stale
  2023-09), `pkg/diff` (stale 2024-12, API unsettled), go-udiff's own
  `myers` subpackage (marked `Deprecated: moribund` — the main package's
  `Lines` is the maintained line entry point). This is dependency-policy
  proposal #1 (root AGENTS.md: extensive web search, evidence above, user
  approved 2026-08-23) and the sole new dependency in 0.3.0; `go.mod` picks it
  up when this task (N) lands. Edge-case
  counts may differ from yolo's 0.2.0 DP-LCS → deviation (behavior, parity
  fix). Pins: write/edit tests get added/removed-count cases.
- **O. Style break** (row 37): `+` line-break of the 294-col glob schema
  string; emitted bytes stay identical (sha256 pin verifies).

### 3.4 Server (`internal/server`)

- **P. Provider-auth scoping** (row 18): `handleProviderAuth` resolves the
  scope dir from `x-yolo-directory` like `GET /provider` (via `scoped()`),
  dropping the hardcoded `s.WorkDir`.

### 3.5 TUI (`internal/tui`)

- **Q. Live footer** (row 5): transient SSE drops (resyncMsg) flip the footer
  to a non-"live" state for the outage window (e.g. `reconnecting`),
  restored on re-hydrate; terminal `connLostMsg` behavior unchanged.
- **R. SSE scanner limit** (row 9): raise the scanner max token to a value
  that tolerates escaped tool output (the finding's 1 MiB is too small for
  ~700 KB+ escaped payloads — the escaped form is ≥2× the raw); on overflow
  the existing abort+resync path still bounds damage.
- **S. Draft concat** (row 26): soft-enter newline append amortized (builder
  or `strings.Builder`-backed field).
- **T. InterruptMsg** (row 20): the TUI model handles `tea.InterruptMsg` (SIGINT
  during Run) the same as the ctrl+c keystroke — opens the quit-confirm dialog.
- **U. Test pins** (rows 24, 25): pin key→reply wiring observables (1→once,
  2→always, 3→reject persisted-rule state) and execute the model-dialog 'b'
  path end-to-end (assert the config PATCH target/field).
- **V. Naming cluster** (rows 29-36): predicate-form bools with JSON-tag
  changes (row 29 — **wire deviation, logged**), `SessionStatus`-prefixed
  constants (row 30), drop the `fakellm` alias (row 31), `client.Client` →
  package-level `New`/functions or `Service` (row 32), `store.Store` →
  `store.Model`/`State` (row 33), `client: ` sentinel prefixes (row 34 —
  status-line text change, render deviation), `dlgNone` sentinel so the zero

### 3.6 CLI + e2e (`cmd/yolo`, `scripts/`)

## 6. Subagent & process constraints (restated from root)

Subagents one at a time (principle 7); a YOLO root spawns only YOLO subagents
(principle 8); no direct `main` commits; task state in beads only (principle
6); the v0.1.2 review's fix policy B (untagged-status findings carry a
contract-risk tag) keeps applying to anything this slice discovers new.
